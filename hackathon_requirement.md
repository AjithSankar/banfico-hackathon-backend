Hackathon Challenge: Build an AI-Powered Fintech Experience
Challenge Overview
Design and build an intelligent fintech application powered by Banking APIs and AI-driven
product development.
Participants will use the provided banking APIs to aggregate customer financial data and create
an innovative, user-centric platform that demonstrates the future of digital banking and
embedded finance.
The objective is to combine:
- Finance capabilities (AIS concepts)
- AI-powered powered development
- Smart financial workflows
  The focus is not only on consuming APIs, but on creating meaningful financial experiences using
  data intelligence and automation.
  Problem Statement
  Traditional banking applications provide fragmented financial information and limited
  intelligence. Customers often struggle to:
- Understand their spending behaviour
- Gain actionable financial insights
- Manage finances across accounts
- Automate routine financial activities
  Your task is to build a next-generation fintech application that leverages Banking APIs and AI
  capabilities to provide:
- Unified financial visibility
- Intelligent spending insights
- Personalized recommendations
- Conversational financial assistance
- Smart payment workflows
  APIs Provided
  Participants will receive a Postman collection containing the following APIs:
  • Accounts API – Create & Retrieve customer account information
  • Balances API – Retrieve current account balances
  • Transactions API – Create transaction & Retrieve transaction history
  These APIs simulate AIS (Account Information Services) capabilities.
  Core Requirements
1. Financial Data Aggregation
- Create a portal with home page and login page
- Fetch and display account information
- Retrieve balances
- Retrieve transaction history
- Provide a unified dashboard view
2. Financial Insights
- Spending summaries
- Monthly spending analysis
- Category-wise expenditure insights
- Income vs expense trends
- Unusual spending detection
- Financial health observations
  Bonus Features (Optional, have anything that they want)
- Build a chatbot or conversational assistant
- Support natural language financial queries
- Predictive analytics
- Budget recommendations
- Savings goals
- Subscription detection
- AI-generated financial coaching
- Voice-enabled interaction
- Personalized dashboards
- Multi-account analytics
- Fraud/anomaly detection
- Workflow automation
- GenAI-powered financial assistant
- MCP/AI Agent integration
- Real-time notifications
  Technical Expectations
  Participants are free to use any technology stack and any of the AI models/tools.
  Deliverables
1. Working prototype/demo
2. Architecture overview
3. README with setup instructions
4. Short presentation/demo walkthrough
   Evaluation Criteria
   • Innovation & Creativity – 25%
   • User Experience & Design – 20%
   • Technical Implementation – 20%
   • AI Usage Capabilities – 20%
   • Effective Use of APIs – 10%
   • Presentation & Demo – 5%
   Suggested User Journey
1. User connects financial accounts
2. Application aggregates account and transaction data
3. Application analyzes spending behaviour
4. User interacts through interactive UI
5. Platform generates recommendations and smart workflows
   What We Want to See
   We are looking for teams that can demonstrate:
- Creativity
- Practical fintech innovation
- Strong API integration
- AI-powered development
- Seamless and intuitive UX
- Vision for the future of Banking
  This hackathon is an opportunity to showcase how Banking APIs combined with AI can
  transform traditional banking into intelligent financial ecosystems.
